# 예제 작업 폴더

DocBench 를 처음 켜 볼 때 쓰는 폴더입니다. 문서 내용은 가상의 팀 기준이며, 일부러 까다로운 경우를 넣어 두었습니다.

| 파일 | 넣어 둔 경우 |
|---|---|
| `docs/설계-노트.md` | 같은 이름의 제목 두 번, `9/29~10/2` 같은 물결표 범위, 표·코드 블록 |
| `docs/운영-런북.md` | 빈칸 표시 `[작업 후 기입]`, TODO, 체크리스트 |
| `docs/질의응답.md` | 3단 깊이 문답 — 접기·펼치기와 접힌 덩어리 피드백 |
| `notes/윈도우-메모.md` | UTF-8 BOM + CRLF (저장 후에도 그대로 유지되는지) |
| `notes/옛-회의록.md` | EUC-KR(CP949) 인코딩 |
| `data/지표.csv` | 문서가 아닌 파일 — 폴더 지도에만 보입니다 |

## 켜 보기

```
node bin/docbench.mjs serve examples/sample-workspace
```

브라우저에서 `http://127.0.0.1:4317/` 을 엽니다.
