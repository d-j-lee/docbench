# DocBench 시작하기

사람과 Claude 가 **같은 문서**를 읽고, 피드백을 주고받고, 고친 이력을 남기는 작업대입니다.
문서는 이 PC 의 폴더에 그대로 있고, DocBench 는 어디로도 보내지 않습니다(Claude 에게 맡길 때만 그 일에 필요한 글이 내 Claude 계정으로 Claude 에게 갑니다).

## 1. 폴더 열기

왼쪽 위 **시작하기**(지금 작업 공간의 이름)를 누르고 **폴더 열기…**를 고르세요.

- 드라이브나 큰 폴더를 열어도 바로 뜹니다 — 탐색기처럼 **펼친 폴더만** 읽습니다.
- 폴더를 열면 **개요**부터 보입니다 — 이 공간이 무엇을 위한 곳인지(맨 위 README 의 첫 문단), 무엇이 들었는지, 살펴볼 것(비밀로 보이는 파일·판 사본·깨진 링크·검토 기한 …). 왼쪽 **작업대 › 개요**로 언제든 돌아옵니다.
- 문서를 누르면 열립니다 — 마크다운은 물론 YAML·JSON 같은 설정 파일(키마다 섹션), CSV 표, 글·로그, Word·PowerPoint·Excel·한글(HWPX)·Jupyter(글을 뽑아 읽기만), PDF·그림까지. 작업대가 열지 않는 파일은 흐리게 보입니다(코드는 기본으로 빠집니다).
- 자주 보는 폴더·문서는 줄 끝의 핀으로 **고정**하면 위쪽 "작업 중"에 늘 있습니다.
- 휴대폰·태블릿 브라우저는 폴더에 쓰지 못해 **둘러보기와 연습**까지만 됩니다. 내 문서와 Claude 작업은 PC 의 엣지·크롬에서 여세요.

## 2. 읽으며 적어 두기

- 문서는 제목마다 **섹션**(제목 하나와 그 아래 글)으로 나뉩니다. 키 `1`은 목차만, `0`은 전부 펼칩니다.
- 섹션 옆 말풍선을 누르거나 문구를 고르면 **그 자리에 작은 칸**이 열립니다. 적은 것은 **초안**으로 모이고 아직 아무에게도 가지 않습니다 — 읽어 가며 고치고, 지우고, 합치세요.
- 요청 문구가 고민되면 **이렇게 바꿔**로 바꿀 글을 직접 쓰거나 *줄이기·근거·표로* 같은 단추를 누르세요. 급한 것은 **★**.
- 직접 고쳐도 됩니다(섹션 단위). 그사이 다른 사람이나 프로그램이 같은 곳을 바꿨으면 차이를 보여 주고 고르게 합니다.

처음 저장할 때 **기록 폴더**(피드백·이력을 둘 곳)를 고릅니다. 문서 폴더에는 아무것도 만들지 않습니다. HTML 파일을 더블클릭해 열었다면 새 창마다 문서 폴더와 기록 폴더를 다시 고릅니다(같은 곳을 고르면 기록이 이어집니다).

## 3. Claude 와 주고받기

- 다 읽었으면 오른쪽 검토 패널의 **초안**에서 보낼 것을 고르고(★만 먼저도 됩니다), 묶음 전체에 붙일 말을 한 줄 적어 **보내기**. 하나씩 따로 가지 않고 한 번에 갑니다.
- **바로 고치기**(기본)면 Claude 가 문서를 고치고, **제안만**이면 고친 글을 제안으로 올립니다. 결과는 **볼 것**에 회차별로 모이고, 하나씩 확인·되돌리기·다시 요청을 고릅니다.
- 내가 다 읽기 전에 **Claude 검토**로 먼저 제안·질문을 받거나, 긴 문서를 **읽기 정리**(접을 곳·먼저 볼 곳)해 달라고 할 수도 있습니다.
- Claude 가 먼저 남긴 의견과 질문은 **볼 것**의 "Claude 가 먼저 남긴 것"에 모입니다. 의견에 동의하면 **반영해** 한 번, 질문에는 **답하기**.

| 연결 | 하는 일 | 준비 |
|---|---|---|
| 터미널 한 줄 | 보내면 명령 한 줄이 나옵니다. PowerShell 에 붙여 넣으면 Claude Code 가 기록 폴더에서 처리하고, 이 화면이 결과를 받아 반영합니다 | Claude Code (DocBench 설치 없음) |
| 이 화면에서 바로 | 백그라운드로 처리하고 진행이 아래 창에 보입니다 | DocBench 앱 (문구 하나로 설치) |
| 대시보드에서 | 쓰던 대시보드의 탭으로 끼워 넣습니다 | DocBench 앱 + 연결 한 줄 |

Claude 는 내 **구독 로그인 그대로** 씁니다(API 키 없음). 문서를 직접 고치지 않고 결과만 내며, 작업대가 그사이 문서가 바뀌지 않았는지 확인해 반영하고 이력을 남깁니다.

> 이 연습 공간에서는 **흉내 Claude** 가 답합니다(실제로 보내지 않음). 연습용 기획서의 **일정** 질문에 **답하기**로 값(예: 11월 3~14일, 김민지)을 적어 보내거나, "이렇게 바꿔"로 초안을 몇 개 만든 뒤 한 번에 보내 보세요 — 고침 → 볼 것 → 되돌리기까지 미리 볼 수 있습니다. 위의 **Claude 검토**도 눌러 보세요.

## 4. 이름과 계정

이름을 묻지 않습니다. 이 브라우저에 계정이 저절로 생기고, 오른쪽 위 **나**를 누르면 표시 이름을 정할 수 있습니다(여럿이 함께 쓸 때 서로 구분됩니다).

## 5. 더 둘러보기

왼쪽 목록의 **활용 가이드** 폴더에 세 문서가 더 있습니다. 모두 연습용이라 적고 보내 봐도 됩니다.

- **직군별 활용** — 개발부터 인사, 법무, 리더까지 직군마다 쓰는 법
- **사용 팁** — 읽기·적기·보내기·볼 것을 빠르게, 상황별 레시피와 단축키
- **효용과 한계** — 무엇이 달라지는지, 재 보는 법, 자주 묻는 질문, 아직 안 되는 것
