# 효용과 한계

> 한 줄로: 읽으며 모은 의견을 한 번에 맡기고, Claude 가 한 일은 확인하거나 되돌립니다. 문서는 내 폴더에 그대로 있습니다.

## 전과 후

| 지금 흔한 방식 | DocBench 에서는 |
|---|---|
| 의견이 메신저·메일·회의록에 흩어진다 | 의견이 문서의 그 섹션, 그 문구에 붙는다 |
| AI 채팅에 문단을 하나씩 붙여 넣고, 고친 글을 다시 문서로 옮긴다 | 읽으며 모은 의견을 한 번에 보내고, 결과가 문서에 바로 반영된다 |
| 무엇이 반영됐는지 원문과 다시 대조한다 | 회차마다 고침·제안·질문·못 함이 나뉘어 올라온다 |
| AI 가 고친 글이 마음에 안 들면 손으로 되살린다 | **되돌리기** 한 번 |
| 누가 언제 왜 바꿨는지 모른다 | 섹션마다 누가·언제·어떤 의견으로 바꿨는지 남는다 |
| 검토하려면 원본을 다른 도구로 옮긴다 | 원본은 내 폴더의 `.md` 그대로, 손대지 않은 줄은 글자 하나·줄바꿈 하나도 그대로 |

## 쓰기 쉬운 점

- 설치 없이 파일 하나(HTML)를 엣지·크롬으로 엽니다. 처음에는 이름도 폴더도 묻지 않고 이 연습 공간이 뜹니다.
- Claude 는 내 구독 로그인 그대로 씁니다. Claude Code 를 쓸 수 있는 구독이면 API 키도, 따로 낼 돈도 없습니다(쓴 만큼 구독 사용량에 들어갑니다).
- 적기와 보내기를 나눴습니다. 고민하며 적고, 다 읽은 뒤 한 번에 보냅니다. 급한 것만 먼저 보내도 됩니다.
- Claude 에게 맡기는 길은 앱의 단추 하나, 또는 **Claude Code 에서 열기** 한 번입니다(처음 한 번은 Claude Code 가 묻는 "이 폴더를 믿나요?"에 Yes).

## 어디에나 쓰는 점

- **직군을 가리지 않습니다**: 마크다운으로 쓰는 문서면 설계 문서부터 규정, 보도자료까지 같은 방식으로 다룹니다(**직군별 활용** 참고).
- **어디서나 같은 화면**: 파일 하나, 이 PC 의 앱, 사내 대시보드의 탭에서 같은 화면이 뜨고, 같은 기록 폴더를 쓰면 기록이 이어집니다.
- **있는 문서 그대로**: 드라이브 같은 큰 폴더, 옛 한글 형식(EUC-KR), Windows 줄바꿈도 바꾸지 않고 다룹니다.
- **사내망에서도**: 화면에 필요한 것이 파일 하나에 다 들어 있어 인터넷에서 따로 받아 오는 것 없이 돕니다.

## 믿고 맡길 수 있는 까닭

- **Claude 는 문서를 직접 고치지 않습니다**: 고친 글을 정해진 모양으로 돌려주면 DocBench 가 그사이 문서가 바뀌지 않았는지 확인해 반영합니다. 그사이 사람이 같은 섹션을 고쳤으면 덮지 않고 제안으로 돌립니다.
- **권한을 좁혀 둡니다**: 앱으로 맡기면 Claude 는 문서 폴더 밖에서 읽기 도구만 가지고 실행되어, 문서 속 글이 속이려 해도 명령을 실행하거나 폴더 밖을 읽지 못합니다. 터미널 한 줄로 맡기면 기록 폴더의 권한 설정이 결과 파일만 묻지 않고 쓰게 하고 기록은 고치지 못하게 막습니다. 그 밖의 일은 (기본 설정이면) Claude Code 가 먼저 묻습니다.
- **사람이 확인해야 끝납니다**: 결과는 확인할 때까지 **볼 것**에 남고, 잘못 고친 것은 되돌립니다.
- **기록은 사람이 읽을 수 있게**: 피드백과 이력은 메모장으로도 열리는 글 파일(JSON)로 기록 폴더에 남습니다. 도구를 그만 써도 기록은 남습니다.

## 자주 묻는 질문

- **질문:** 회사 문서가 밖으로 나가나요?
- **답:** 화면만 쓸 때는 아무것도 나가지 않습니다(이 파일은 바깥 연결을 막아 둡니다). Claude 에게 맡기면 그 일에 필요한 글과 Claude 가 문서 폴더에서 읽은 내용이 내 Claude 계정으로 Claude 에게 갑니다. 회사 문서라면 사내 AI 사용 기준을 먼저 확인하세요.
- **질문:** 진짜 Claude 를 쓰려면 무엇이 필요한가요?
- **답:** Claude Code 를 쓸 수 있는 Claude 구독과, 이 PC 에 설치한 Claude Code 입니다. 화면만 쓰는 데는 아무것도 필요 없습니다.
- **질문:** 워드·한글 문서도 되나요?
- **답:** 지금은 마크다운이 대상입니다. 초안과 검토는 `.md` 로 하고 서식은 마지막에 원래 프로그램에서 입힙니다.
- **질문:** AI 가 문서를 망치면요?
- **답:** Claude 는 고친 글만 돌려주고, 결과는 확인할 때까지 볼 것에 남습니다. 되돌리기 한 번이면 고치기 전 글로 돌아갑니다.

## 한계

- **마크다운이 대상입니다**: 워드·한글 문서는 `.md` 로 바꿔 검토합니다(**사용 팁**의 "워드·한글 문서는").
- **진짜 Claude 는 Claude Code 로 연결됩니다**: 다른 AI 는 아직 붙여 보지 않았습니다. 요청과 결과가 기록 폴더의 파일로 오가므로, 같은 모양으로 결과를 내는 도구라면 끼울 자리는 있습니다.
- **실시간 공동 타이핑은 없습니다**: 섹션 단위로 저장하고, 겹치면 차이를 보여 주고 고르게 합니다.
- **Claude 에게 맡긴 내용은 Claude 로 갑니다**: DocBench 자체는 문서를 밖으로 보내지 않지만, 보내기를 누르면 그 일에 필요한 글이 내 Claude 계정으로 전달됩니다. 회사 문서라면 사내 AI 사용 기준을 따르세요.
- **휴대폰은 보기와 연습까지**: 폴더에 쓰려면 PC 의 엣지·크롬이 필요합니다.
- **이 연습 공간의 Claude 는 흉내입니다**: 정해진 규칙으로만 답합니다. 진짜 Claude 는 PC 에서 폴더를 열고 연결하면 씁니다.
