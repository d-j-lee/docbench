# 사용 팁

> 처음 하루 동안 알아 두면 좋은 것들입니다. 위에서부터 읽어도 되고, 필요한 절만 펼쳐도 됩니다(키 `1`은 목차, `0`은 전부).

## 읽기

- **깊이로 훑기**: 키 `1`은 큰 제목만 보이는 목차입니다. 제목 단계가 더 깊은 문서는 `2` `3`으로 한 단계씩 펼칩니다. 접은 상태는 다음에 열어도 그대로입니다.
- **찾기**: `/` 를 누르면 접힌 섹션 안까지 찾습니다.
- **근거 표기**: `[실측]` `[문서]` `[조사]` `[추정]` `[미확인]`을 쓰면 색으로 나뉩니다. 어느 숫자가 잰 값이고 어느 것이 추정인지 바로 보입니다.
- **빈칸**: `[작업 후 기입]`, `[확인 필요]`, `TODO` 는 형광으로 보이고 문서 위에 빈칸 수가 나옵니다.
- **이름표만 보기**: 목록 줄이 `**질문:**`, `**답:**`처럼 굵은 이름표로 시작하고 세 번 이상 반복되면 문서 위에 이름표 칩이 뜹니다. **질문**을 누르면 답 줄이 숨어 혼자 답해 보며 복습할 수 있습니다(**효용과 한계**의 "자주 묻는 질문"에서 해 보세요).
- **작업 중 고정**: 자주 여는 문서와 폴더는 줄 끝 핀으로 고정해 위쪽 "작업 중"에 둡니다.
- **바뀐 곳**: 마지막으로 본 뒤 바뀐 글은 문서 위에 바로 표시됩니다(더한 글 초록, 지운 글 취소선, 누가·언제). 다 봤으면 **표시 지우기**.

## 적기

- **어디에나**: 섹션 옆 말풍선은 그 섹션 전체에, 문구를 고르면 그 문구에, 문서 위 **문서 전체에**는 문서 하나에 적습니다. 접힌 섹션에 적으면 그 아래 내용 전체가 대상입니다.
- **초안은 아무 데도 안 갑니다**: 적은 것은 초안으로 모일 뿐입니다. 읽으면서 고치고, 지우고, 합치세요(**합치기**: 같은 섹션이면 그 섹션에, 여러 섹션이면 문서 전체 요청으로).
- **문구가 고민되면**: 자주 쓰는 말 단추(**줄이기 · 쉽게 · 근거 · 표로 · 접기 · 나누기 · 빼기 · 확인만**)를 누르거나, **이렇게 바꿔**로 바꿀 글을 직접 씁니다. "왜"를 한 줄 덧붙이면 Claude 가 의도를 덜 놓칩니다.
- **고치지 말고 묻기**: **확인만**은 "맞는지 확인해 주세요(고치지 말고 답만)"를 넣습니다. 처음 맡은 규정·매뉴얼을 읽다 생긴 질문을 그 자리에 적어 두었다가 한 번에 보내면 답이 **볼 것**에 모입니다.
- **급한 것**: ★ 를 켜 두면 나중에 **★만** 골라 먼저 보낼 수 있습니다.
- **글을 잃지 않게**: 적다가 다른 곳에 새로 적거나 문서를 옮기면 적던 글은 초안으로 남습니다. Esc 는 한 번 더 눌러야 버립니다.
- **키보드로**: `c` 는 지금 섹션에 적기, `Ctrl+Enter` 는 초안에 두기, `Ctrl+Shift+Enter` 는 이것만 바로 보내기.

## 보내기

- **다 읽고 한 번에**: 검토 패널 **초안**에서 보낼 것을 고르고 **보내기**. 하나씩 따로 가지 않고 한 요청으로 갑니다.
- **붙일 말**: 이번 묶음 전체에 붙일 말을 한 줄 적습니다. 예: "존댓말 유지, 표의 숫자는 그대로".
- **반영 방식**: **바로 고치기**는 분명한 요청을 바로 고치고(되돌릴 수 있음), 큰 변경은 제안으로, 모르는 것은 질문으로 돌려줍니다. **제안만**은 문서를 그대로 두고 고친 글을 제안으로만 올립니다. 고른 방식은 기억됩니다.
- **늘 지킬 지시**: 매번 같은 말을 붙이고 있다면 **늘 지킬 지시**에 한 번 적어 두세요. 보낼 때마다 함께 갑니다.
- **어디로**: 이 PC 의 DocBench 앱(백그라운드 처리, 진행 로그), **터미널 한 줄**(DocBench 설치 없이 지금 쓰는 Claude Code 로 — **Claude Code 에서 열기** 단추 하나), 대시보드 탭 중에서 고릅니다. 모두 내 구독 로그인 그대로이고 API 키가 필요 없습니다.

## 볼 것

- **회차별로**: 한 번 보낸 묶음이 한 회차입니다. 회차 머리에 붙인 말과 Claude 의 요약이 보입니다.
- **고침**: **바뀐 곳**으로 전후를 보고 **확인**, 마음에 안 들면 **되돌리기**(고치기 전 글로), 다르게 하려면 **다시 요청**. 되돌린 뒤 다시 보내면 Claude 에게 되돌렸다는 사실이 함께 갑니다.
- **제안**: 차이를 보고 **적용** 또는 **거절**. **질문**: **답하기**로 답하면 초안이 되어 다음 묶음과 함께 갑니다.
- **Claude 가 먼저 남긴 것**: 의견에 동의하면 **반영해** 한 번(단축키 `a`), 다르게 하려면 답하기, 필요 없으면 닫기. 질문에는 답하기.
- **못 함**: 반영하지 못한 것은 까닭과 함께 올라옵니다. **다시 보내기** 또는 **초안으로**.
- **모두 확인 · 이 회차 되돌리기 · 요약 복사**: 회차 머리의 단추입니다. 요약은 팀 공유나 커밋 메시지에 그대로 붙입니다.
- **키보드로**: `f` 로 검토 패널을 열고(또는 패널 안을 한 번 누르고) `j` `k` 로 카드를 오가며 `a`(확인·적용·반영해), `u`(되돌리기), `r`(답하기).

## Claude 먼저

- **제안·질문 받기**: 내가 다 읽기 전에 Claude 가 먼저 읽고 고칠 곳은 제안으로, 모르는 곳은 질문으로 올립니다. 범위는 이 문서, 지금 섹션, 같은 폴더의 문서(최대 10개) 중에서 고릅니다. 폴더로 고르면 문서 사이의 어긋남(용어·숫자·중복)도 짚게 합니다.
- **읽기 정리**: 긴 문서에서 먼저 볼 곳은 펼치고 나머지는 접어 둡니다. 문서는 그대로이고 내 화면만 바뀌며, 되돌릴 수 있습니다. 아직 확인하지 않은 바뀐 섹션은 접지 않습니다.

## 함께 쓰기

- **표시 이름**: 오른쪽 위 **나**에서 이름을 정하면 여럿이 쓸 때 누가 적고 고쳤는지 구분됩니다.
- **기록 폴더**: 처음 저장할 때 고릅니다. 혼자 쓰면 문서 폴더 밖의 기록 보관함, 팀이 git 으로 나누면 **문서 폴더 안에 두기**(`.docbench`). HTML 파일을 더블클릭해 열었다면 새 창마다 다시 고릅니다(같은 곳을 고르면 기록이 이어집니다).
- **덮어쓰지 않습니다**: 저장할 때마다 그사이 문서가 바뀌었는지 확인합니다. 다른 섹션이 바뀌었으면 최신 글에 내 고침을 다시 넣고, 같은 섹션이 바뀌었으면 내 글을 지킨 채 차이를 보여 줍니다.
- **초안은 내 것만**: 보내기 전의 초안은 적은 사람에게만 보입니다. 함께 보는 것은 보낸 뒤의 결과와 이력입니다.

## 파일과 환경

- **문서는 그 자리에**: 원본은 내 폴더의 `.md` 파일 그대로이고 DocBench 는 어디로도 보내지 않습니다.
- **옛 형식도 그대로**: 옛 한글 형식(EUC-KR)이나 Windows 줄바꿈 문서도 고치지 않은 줄은 원래 모양 그대로 저장합니다(IT 담당자용: CP949·UTF-16LE·BOM·CRLF). 그 형식으로 저장할 수 없는 글자가 들어가면 저장 전에 묻습니다.
- **큰 폴더도 바로**: 드라이브를 통째로 열어도 탐색기처럼 펼친 폴더만 읽습니다.
- **휴대폰**: 휴대폰·태블릿 브라우저는 폴더에 쓰지 못해 둘러보기와 연습까지 됩니다.
- **마크다운이 처음이라면**: 메모장으로도 쓰는 글 파일입니다. `#` 으로 시작하는 줄이 제목이고 제목마다 섹션이 됩니다(`##` 는 한 단계 아래). `-` 는 목록, `|` 로 나눈 줄은 표입니다. 메모장에서 이름을 `.md` 로 저장하면 새 문서가 됩니다.
- **워드·한글 문서는**: 초안과 검토는 `.md` 로 하고, 서식은 마지막에 원래 프로그램에서 입히는 흐름이 가장 편합니다. 바꾸는 일은 Claude Code 에 "이 워드 파일을 .md 로 바꿔 줘"라고 맡기면 됩니다.

## 상황별 레시피

| 상황 | 이렇게 |
|---|---|
| 회의 10분 전, 긴 보고서 | Claude 검토 → 읽기 정리 → 펼쳐진 곳만 읽고, 질문은 그 자리에 적기 |
| 팀장 의견 20개 반영 | 하나씩 적어 초안으로 → ★만 먼저 보내기 → 나머지는 한 번에 |
| 회의록에서 할 일만 뽑고 싶다 | 맨 끝에 `## 할 일` 제목과 빈 표(할 일·담당·기한)를 두고 **문서 전체에** "논의에서 결정과 할 일을 뽑아 이 표를 채워 줘. 모르는 칸은 `[확인 필요]`" → 보내기 → 형광으로 남은 칸만 사람에게 묻기 |
| 매번 같은 지적을 받는다 | 그 지적을 늘 지킬 지시에 한 줄로 |
| Claude 가 고친 글이 아쉽다 | 되돌리기 → 다시 요청에 이유 한 줄 |
| 개정 내용을 공지해야 한다 | 회차를 확인한 뒤 요약 복사 → 공지문에 붙이기 |
| 남이 쓴 문서를 처음 맡았다 | 키 `1`로 목차 → Claude 검토(같은 폴더) → 질문부터 답하기 |
