## 씨앗 (지금은 안 쓰지만 남겨 둔 방향)

- **S1 MCP 서버**: CLI 명령을 MCP 도구로 감싸면 Claude Desktop·다른 에이전트도 같은 프로토콜로 붙는다. `bin/docbench.mjs` 의 명령 구현을 그대로 재사용하면 된다.
- **S2 해결 = 커밋**: 피드백을 반영할 때 git 커밋을 하나씩 만들면 이력이 저장소 히스토리와 일치한다(`changes.jsonl` 에 커밋 해시 추가).
- **S3 다른 저장소 어댑터**: Google Drive·Notion·사내 위키를 `DocSource` 로. 판 비교만 지키면 화면은 그대로.
- **S4 실시간 공동 편집**: 지금은 섹션 단위 낙관적 잠금. 필요해지면 섹션 안만 CRDT.
- **S5 피드백 → 작업 목록**: 사람 차례 피드백을 대시보드의 할 일로 내보내기(이벤트 `feedback:updated` 로 충분).
