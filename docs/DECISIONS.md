- **S1 MCP 서버**: CLI 명령을 MCP 도구로 감싸면 Claude Desktop·다른 에이전트도 같은 프로토콜로 붙는다. `bin/docbench.mjs` 의 명령 구현을 그대로 재사용하면 된다.
- **S2 해결 = 커밋**: 피드백을 반영할 때 git 커밋을 하나씩 만들면 이력이 저장소 히스토리와 일치한다(`changes.jsonl` 에 커밋 해시 추가).
- **S3 다른 저장소 어댑터**: Google Drive·Notion·사내 위키를 `DocSource` 로. 판 비교만 지키면 화면은 그대로.
- **S4 실시간 공동 편집**: 지금은 섹션 단위 낙관적 잠금. 필요해지면 섹션 안만 CRDT.
- **S5 피드백 → 작업 목록**: 사람 차례 피드백을 대시보드의 할 일로 내보내기(이벤트 `feedback:updated` 로 충분).
- **S6 세션 시작 안내 훅**: 플러그인에 SessionStart 훅을 두어, Claude Code 가 `.docbench/` 가 있는 폴더에서 시작하면 "요청함 N건 · AI 차례 M건" 한 줄을 맥락에 넣는다(훅 stdout 이 맥락이 됨 — 공식 문서). 대시보드가 터미널에 입력을 못 밀어 넣을 때 넘기기를 이어 주는 길.
- **S7 GitHub Release**: `release/docbench.html` 과 `npm pack` 의 tgz 를 릴리스 첨부로 — 버전별 내려받기 주소가 생긴다.
- **S8 폴더 어댑터의 FileSystemObserver**: 크롬이 정식으로 내면 2.5초 확인을 실제 알림으로 바꾼다.
- **S9 요청별 사람**: `createDocBenchHandler(ws, { identify(req) })` 로 대시보드 로그인 사용자를 작성자·보기 상태 주인으로. 지금은 서버 방식의 모든 쓰기가 한 사람(이 PC 의 `user`)이다.
- **S10 단일 HTML 의 상대 경로 그림**: → D89 로 실현(서버·단일 HTML 모두 `loadBytes` 로 Blob).
- **S11 실행용 묶음**: `npm pack` tgz 를 릴리스 첨부로 — 사내망에서 빌드 도구 없이 받는다(지금은 `npm install --omit=dev --ignore-scripts` 로 확인된 길).
- **S12 플러그인 monitor**: 플러그인 `experimental.monitors` 로 열린 Claude Code 세션이 `.docbench/inbox/` 의 새 요청을 알림으로 받게 — 대화형 세션에서 넘기기를 이어 주는 길(D43 에서 백그라운드 실행을 택했다).
- **S13 실행기 여러 폴더**: → D67 DocBench 앱으로 실현(실행기는 예전 연결을 위해 남김).
- **S14 작업 이어 쓰기**: `--session-id`·`--resume` 으로 같은 피드백의 다음 작업이 지난 맥락을 잇게(지금은 `--no-session-persistence`).
- **S15 Windows 서비스형 실행기**: 시작프로그램 .cmd 대신 작업 스케줄러·서비스 — 회사 정책에 따라.
- **S16 CLI 로 기록 옮기기**: `docbench data move <문서 폴더> --data <기록 폴더>` — 서버 방식 폴더도 안쪽 `.docbench` 를 밖으로(지금은 단일 HTML 의 "보관함으로 옮기기"만).
- **S17 문서 옆 임시 파일 없애기**: 저장 때 잠깐 생기는 `.<이름>.docbench-….tmp`(서버)를 기록 폴더 `tmp/` 에서 만들어 옮기기(같은 드라이브일 때만 — 다르면 지금처럼). 브라우저의 `.crswap` 은 브라우저 동작이라 못 없앤다.
- **S18 앱 트레이 아이콘**: 로그인 때 켜는 .cmd 대신 알림 영역 아이콘(켜짐·Claude 작업 중·할 일 수). 서명·설치 부담 때문에 미룸.
- **S19 대시보드의 사람**: host.js `mount({ user })` 로 대시보드 로그인 사용자를 작성자로(S9 의 iframe 판) — 지금은 이 PC 의 로그인.
- **S20 기록 합치기 CLI**: `docbench data merge <넓은 폴더>` — 서버·CLI 로만 쓰던 하위 폴더 기록도(지금은 앱·단일 HTML 이 열 때 묻는다).
- **S21 아티팩트 안의 Claude 로 바로 반영**: claude.ai 아티팩트의 모델 호출(`assistant.propose` 가 쓰는 길)을 "어디로"의 한 갈래로 — 대화창에 보내지 않고 그 자리에서 제안을 받아 "볼 것"에. 지금은 대화창으로만 보낸다(D78).
- **S22 문단 단위 바로 고치기**: 섹션 편집기 대신 문단을 두 번 눌러 그 자리에서 마크다운을 고치기(바이트 보존·판 비교는 섹션 쓰기와 같게).
- **S23 정해 둔 때 Claude 검토**: 예약 작업으로 바뀐 문서를 Claude 가 먼저 읽고 "볼 것"에 올려 두기(D74 를 시간에 걸기).
- **S24 PDF 글·쪽 미리보기**: pdf.js 로 글을 뽑아 섹션·찾기·인용까지(지금은 내려받기 카드, Claude 는 Read 로 직접). 번들이 수 MB 늘어 단일 HTML 에 무겁다 — 필요할 때 따로 싣는 길로.
- **S25 도식 그리기**: Mermaid·PlantUML·Graphviz 원문을 그림으로(지금은 색 입힌 원문). 렌더러가 무겁고 CSP(스크립트·바깥 서버)와 부딪친다.

- **S27 점검을 팀 규칙으로**: → D90 으로 실현(`docbench.json` · `docbench check` · GitHub Action).
